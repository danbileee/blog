# Noto Sans JP Japanese webfont

Source: [Google Fonts, revision 66a36c8c94b1a5d992ee4e7f392fccfe4945767c](https://github.com/google/fonts/tree/66a36c8c94b1a5d992ee4e7f392fccfe4945767c/ofl/notosansjp), `NotoSansJP[wght].ttf`, version 2.004-H2.
License: SIL Open Font License 1.1; see `OFL.txt`.

`noto-sans-jp-japanese.woff2` is a single offline FontTools subset of that source, retaining variable weights 100–900 and shaping features. Final size: 3,943,724 bytes. No font-processing tools are runtime dependencies.

Retained Unicode ranges (intersected with the source character map):

```text
U+3000-30FF, U+31F0-31FF, U+3400-4DBF, U+4E00-9FFF, U+F900-FAFF,
U+FE10-FE19, U+FE30-FE4F, U+FF01-FF0F, U+FF1A-FF20, U+FF3B-FF40,
U+FF5B-FF9F, U+1AFF0-1AFFF, U+1B000-1B16F, U+20000-2FA1F, U+30000-323AF
```

The matching CSS `unicode-range` and language rules are in `src/styles/global.ts`. Latin letters, ASCII/full-width digits, Hangul, and private-use icon glyphs are excluded from this face.
